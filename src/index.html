Enable your location

Follow these steps, then tap Try location again.

The browser controls the permission prompt. If access is denied, Alpenwetter cannot force a new prompt or change your settings.

On iPhone or iPad

  1. Open Settings → Privacy & Security → Location Services and turn Location Services on.
  2. In that list, check Safari Websites (and Alpenwetter, if listed). Allow access while using it. German labels: Datenschutz & Sicherheit → Ortungsdienste → Safari-Websites → Beim Verwenden der App.
  3. Open this site in Safari. Open the page menu beside the address bar, then Website Settings → Location → Ask or Allow. You may need to tap … first. German: Website-Einstellungen → Standort → Fragen oder Erlauben.
  4. Tap the location button in Safari. If that works, reopen the Home Screen app and retry there. Browser and installed-app permissions may differ.

Firefox on iOS

Check Settings → Privacy & Security → Location Services → Firefox → While Using the App, if Firefox is listed. Reopen Firefox and tap the location button on this site. Allow any website prompt too. Granting access to Brave does not grant access to Firefox or the installed Home Screen app.
