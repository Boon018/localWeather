# Austrian postcode index

Source: https://download.geonames.org/export/zip/AT.zip, downloaded 2026-10-22.
GeoNames postal data, CC BY 4.0: https://creativecommons.org/licenses/by/4.0/.
Attribution: https://www.geonames.org/.

`austrian-postcodes.json` maps postcode strings to arrays of
`[place, state, latitude, longitude, placeMatchesMunicipality]`.
All 2,501 codes and 19,225 rows in the source are included. Coordinates are
approximate locality references, not addresses or postcode boundary centroids.
No warranty of completeness or accuracy. The snapshot is bundled into both HTML
outputs so Austrian postcode searches work offline and require no extra service.
